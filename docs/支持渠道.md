当前支持采集的公开渠道共 **10 个入口，覆盖 7 类渠道中的 5 类**（另有 2 类合规受限如实标注）。按状态分：

## 已真实接入验证（live_verified，7 个）

| 渠道                                                         | 采集什么                                                     | 增量方式                                 |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ---------------------------------------- |
| **GitHub**                                                   | 仓库当前分支全部文本文件 + **提交历史**（新增/修改文件逐版本扫描） | blob sha 版本缓存 + 历史游标             |
| **Gitee**                                                    | 仓库当前分支文本文件                                         | blob sha 版本缓存                        |
| **MediaWiki 兼容站点**（中文维基百科实测）                   | 最近变更页面的修订内容                                       | `rccontinue` 游标增量续扫                |
| **博客园**                                                   | 首页/订阅源文章正文                                          | ETag/Last-Modified 条件请求（304 跳过）  |
| **Stack Overflow**                                           | 关键词检索的问题标题+正文                                    | 问题 ID+活跃时间版本缓存                 |
| **通用 RSS/Atom/Sitemap/URL**                                | 任何提供订阅源或站点地图的站点的页面文本                     | ETag/LM + lastmod + 内容哈希             |
| **OCI/Docker 容器镜像**（Docker Hub 实测，ghcr/阿里云同协议） | 逐层文件内容，**区分“当前视图可见”与“历史层残留”**（whiteout 语义） | config digest 作镜像版本，层 digest 缓存 |

## 已实现、离线测试通过（2 个）

| 渠道                       | 采集什么                                | 说明                                                         |
| -------------------------- | --------------------------------------- | ------------------------------------------------------------ |
| **Android APK**            | assets/资源/配置文本 + dex 内字符串常量 | 已用 F-Droid 官方 APK 实测过（上传/本地/公开下载 URL 三种入口，整包哈希去重） |
| **未加密 wxapkg 小程序包** | 包内文本条目（js/json/配置）            | 合规边界：**加密包拒绝解密**；线上小程序无合法公开获取途径   |

## 本地导入分析入口（2 个，不计入渠道数）

本地目录 / Git 仓库副本 / 压缩包（zip/tar）——用于分析和测试，统计中单独列出。

## 合规受限（如实标注，不做绕过）

- **微博**：blocked——无合规公开检索接口（需登录态，开放平台搜索不对普通开发者开放）
- **CSDN / 掘金**：planned——无官方接口，合规抓取路径待单独评估

所有渠道共用同一套流水线（预算控制、限流优雅停止、游标增量、去重），新增渠道按 `docs/EXTENSIBILITY.md` 的八步清单扩展即可。完整明细（入口 API、认证要求、限制、验收证据）见 `docs/SUPPORT_MATRIX.md`。
