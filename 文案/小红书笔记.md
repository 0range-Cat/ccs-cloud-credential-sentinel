## 正文

你还在以为把 API Key 写进代码、随手 push 上 GitHub，没人会发现吗？

真实的痛是：很多小伙伴代码一提交，阿里云 AK、AWS 密钥、数据库密码、各种 Token 就跟着一起"公开"了。等收到异常扣费、账号被刷的告警才后知后觉，回头翻仓库历史翻到崩溃，还常常漏掉最要命的那几条……

直到我摸到这个「云上凭据泄露检测」工具，真心觉得干这行的人都该配一个。

📊 一眼看全局（图1）
打开就是总览：检测到多少去重凭据、多少泄露位置、覆盖多少种密钥类型，清清楚楚，比人肉翻快太多。

🛰️ 公开渠道自动盯（图2）
GitHub、Gitee、Wiki、博客、RSS、Stack Overflow……把要盯的仓库或关键词一填，它就自动去采、还能持续监控，不用天天手动搜。

🔑 一把揪出各种密钥（图3）
GitHub 令牌、阿里云 AK、AWS 密钥、Twilio、数据库连接串、私钥……十几类凭据一眼识别，置信度、位置、最近发现时间全列好，还默认打码，绝不会二次泄露。

✅ 最小化验证：密钥还活着吗（图4）
发现后一键验证这条密钥现在还有没有效，只做最轻的"验明正身"，不碰业务数据、不枚举资源，克制又合规。

📋 渠道与规则透明可见（图5）
哪条渠道覆盖到什么程度、检测哪些密钥类型，全摆给你看，还能自己开关规则。

🛡️ 脱敏、限速、预算都能调（图6）
默认脱敏、自动验证开关、采集限速、扫描预算……想保守就保守，把风险牢牢握在自己手里。

适合谁：后端 / 运维 / 安全工程师、独立开发者、所有把代码放到公开平台的人。

密钥泄露这事，宁可早盯一秒，别等出事再补救。慢慢用，真的会上瘾。
